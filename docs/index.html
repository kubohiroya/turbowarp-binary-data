Binary Data for TurboWarp

Store project-scoped named bytes and expose replayable raw body snapshots without converting data to base64 or text.

Enable the MVP

Set globalThis.BINARY_DATA_MVP = true before loading the unsandboxed extension.

Blocks

Create binary data from UTF-8 text, test and delete names, and inspect MIME type, byte length, and SHA-256.

Integration

The JavaScript API accepts ArrayBuffer and Uint8Array. The Named Data provider exposes project-scoped raw snapshots for HTTP responses.
